# Contributing to Instella-Math

Thank you for your interest in contributing to Instella-Math! We welcome
contributions from the community.

## How to Contribute

1. **Fork** the repository and create your branch from `main`.
2. **Make your changes**, keeping commits focused and well described.
3. **Test** your changes locally to ensure nothing is broken.
4. **Open a pull request** against `main` with a clear description of what your
   change does and why.

## Pull Request Guidelines

- All pull requests require review and approval from a code owner
  (see [CODEOWNERS](./.github/CODEOWNERS)) before they can be merged.
- Keep pull requests reasonably scoped — smaller, focused changes are easier to
  review and merge.
- Ensure your branch is up to date with `main` before requesting review.
- Reference any related issues in the pull request description.

## Reporting Issues

- Use **GitHub Issues** for bugs and feature requests.
- For security vulnerabilities, **do not** open a public issue — follow the
  process in [SECURITY.md](./SECURITY.md) instead.

## Code of Conduct

Please be respectful and constructive in all interactions. We aim to maintain a
welcoming and collaborative environment for everyone.
